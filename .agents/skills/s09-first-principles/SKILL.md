# 第一原理思维与获取三法

## R — 原文 (Reading)
> 第一原理的本质是「绝对为真的起点知识」。第一原理思维的本质是「一种极致的求根思维和一种极致的求真思维」。寻找第一原理主要有三大方法：巨人法、收敛法、追问法。
> — 兰陵王, 第06课《第一原理》

## I — 方法论骨架 (Interpretation)
- 第一原理=**绝对为真的起点知识**，不能被省略、删除或违反；第一原理思维=极致的**求根**（追溯起点）+**求真**（实证可靠）。
- 三大功能：收敛知识、看透本质、以简驭繁、超级迁移、超级创造、正确决策。
- 获取三法：①**巨人法**——直接学习巨人已找到的第一原理（效率最高）；②**收敛法**——用树状知识体系不断向上收敛，逼近起点（须靠笔记软件）；③**追问法**——用先验直觉大胆猜本质、再逻辑演绎+经验观察小心求证。
- **类比思维 vs 第一原理思维**：类比只照搬相似经验、难创新（"要更快的马"）；第一原理回到起点重算（"马=动力+运动系统"→汽车），是创造的根本。
- "以强胜弱""以简驭繁"等第一原理，是把知识收敛到起点后驾驭万物的抓手。

## A1 — 书中的应用 (Past Application)
### 案例 1: 马斯克造特斯拉电池的第一原理计算
- **问题**: 电池组市场价约600美元/千瓦时，看似不可撼动。
- **方法论的使用**: 回到起点（从头算）——分解材料成分（钴、镍、铝、碳…）查现货价值，约80美元/千瓦时。
- **结论**: 从第一原理计算，真实成本远低于市场价，应自己造。
- **结果**: 跳出现有经验定价，重构电池方案，对创业者启发极大。

### 案例 2: 作者写《以强胜弱》用追问法获取第一原理
- **问题**: 如何得到"战胜"领域的第一原理？
- **方法论的使用**: 用先验直觉追问本质（同一水平线强者胜），再逻辑推理+经验观察小心验证。
- **结论**: "以强胜弱"是绝对为真的起点——所有以弱胜强本质都是换维度以强胜弱。
- **结果**: 提炼出可覆盖战争、竞争、商业的第一原理。

### 案例 3: 量子论发展史——不断追问+实证检验（求根+求真）
- **问题**: 黑体辐射、光电效应等现象背后的本质是什么？
- **方法论的使用**: 普朗克→爱因斯坦→玻尔→海森堡在现象/前人理论上不断追问；麦克斯韦、相对论等再用赫兹/爱丁顿实验实证。
- **结论**: 知识大厦由"大胆追问+小心求证"一层层建起，求根与求真形影不离。
- **结果**: 建立近代物理学大厦，印证第一原理思维是科学核心。

## A2 — 触发场景 (Future Trigger) ★
### 用户会在什么情境下需要这个 skill?
1. 用户想看透某事物/领域的本质与根源。
2. 用户面临重大决策（创业、战略、择业、投资），想基于根本而非经验拍板。
3. 用户习惯类比同行、难以真正创新（"要更快的马"）。
4. 用户想把零散知识体系收敛到更底层的统一原理。
5. 用户对冲突的格言/模型无所适从，想找到更本质的统摄法则。

### 语言信号
- "这件事的本质是什么？" / "What is the essence of this?"
- "大家都这么做，但我想要根本解法" / "Everyone copies, I want a first-principles solution"
- "如何从根本上降本/破局？" / "How to cut cost / break through from first principles?"
- "为什么这些说法都只对一部分？" / "Why is each model only partly right?"

### 与相邻 skill 的区分
- 与 `s01-san-gui`（归道≈第一原理近似）：三归的"归道"是向内求逼近法则，第一原理更严格——要求"绝对为真的起点"，且强调求真验证。
- 与 `s10-transfer-create`（排列组合需底层原理）：创造=第一原理的排列组合；本 skill 讲"如何获取第一原理"，s10 讲"拿到后如何迁移创造"。
- 与 `s07-model-definition`（模型逼近第一原理）：模型是法则级成果、不要求绝对为真；第一原理要求绝对为真的起点。

## E — 可执行步骤 (Execution)
1. **判断是否需要第一原理** — 完成标准：遇到本质问题/重大决策/收敛需求；判停：若只是一次性具体技巧，用普通模型（s07）即可，不必强求第一原理。
2. **三选一获取** — 完成标准：巨人法（直接学已有第一原理）/收敛法（树状体系向上收敛，依赖 s08）/追问法（先验直觉大胆猜+逻辑演绎+经验观察验证）；至少得到一条可表述的起点知识。
3. **求真验证与标注边界** — 完成标准：用现实检验（可证伪）确认可靠性，并标注其适用边界；若无法实证则谨慎对待、标为"假设"。

## B — 边界 (Boundary) ★
### 不要在以下情况使用
- 把类比当第一原理（"别人都这么做所以我这么做"）。
- 认为第一原理容易找到、或任何结论都标榜"第一原理"。
- 跳过求真验证，仅凭直觉断言"绝对为真"。

### 作者在书中警告的失败模式
- 类比思维主导、不求根求真：只能渐进改良、难创新（ce23）。
- 误解知识孤立发散、不收敛：陷入"学无止境"焦虑（ce25）。
- 误以为存在"以弱胜强"：在对抗中错寄望弱势翻盘（ce24）。

### 作者的盲点/时代局限
- 朴素基础主义色彩：追求"绝对为真的起点"被波普尔**可证伪性**反驳——现实中"绝对为真起点"极少，多数领域只有"当前最可靠假设"。
- 第一原理**极难找**：绝大部分人一辈子未必找到所在行业的第一原理。
- "万物归一、一生万物"是作者归纳未归道的猜想，尚待证实。

### 容易混淆的邻近方法论
- **类比思维**（照搬相似经验、易但浅）vs **第一原理思维**（回到起点重算、累但深）。
- **模型**（相对真理、法则级）vs **第一原理**（绝对为真的起点知识）。
