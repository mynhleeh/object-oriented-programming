# 三归模型：从经验中归纳、归因、归道

## R — 原文 (Reading)
> 我把这个方法称之为「三归模型」：归纳、归因、归道。……经验即感知，思考即三归——归纳、归因、归道。
> — 兰陵王, 第01课

## I — 方法论骨架 (Interpretation)
三归是作者自创的一套"向内求"思考阶梯，用来把亲身经历转化成可复用的认知。
- 归纳：观察反复出现的现象，总结出"规律"（可感知、可预测）。
- 归因：追问是什么导致了这个规律，找出现象之间的"因果"关系（不可直接感知，靠推理）。
- 归道：继续上溯因果的源头，找到支配它的"法则/道"（第一原理级）。
人的感官只能直接看到规律，因果和法则都得靠思考反推，所以越往后越难、也越接近本质。掌握法则的目的是"以不变应万变"。

路径总览：掌握法则有两条总路径。向内求 = 经验 + 三归（从自身经历思考）；向外求 = 直接学习巨人已总结的规律/因果/法则（效率远高于前者）。两者并列，是全书方法论的两条主干。

## A1 — 书中的应用 (Past Application)
### 案例 1: 想通规律、因果、法则的三层关系
- **问题**: 作者做小红书时想不通"控制变量法"的本质。
- **方法论的使用**: 把《道德经》与《西方哲学史》联系起来思考，逐层区分"规律（可感知的反复）—因果（现象相继）—法则（因果之源）"。
- **结论**: 三者是递进层级，而非同义词。
- **结果**: 据此提出"三归模型"，成为全书向内求的方法论核心。（第01课）

### 案例 2: 从爆款标题归结到人性法则
- **问题**: 做自媒体时发现不同标题形式（A/B/C/D）都能成爆款，规律太多无法穷尽。
- **方法论的使用**: 归纳出"某类标题阅读好"的规律后继续归因、归道，追问这些形式背后的共同因果与法则。
- **结论**: 它们都利用了人性的"贪婪"与"恐惧"。
- **结果**: 提炼出"爆款标题本质是激发人性贪婪/恐惧"的法则级认知。（第01课）

### 案例 3: 向内求三年 vs 向外求一小时
- **问题**: 作者早期做自媒体，花了三年才悟透"选题"的重要性。
- **方法论的使用**: 对比两条路径——靠自身经验三归（慢），与直接学习巨人已得结论（快）。
- **结论**: 向外求能把悟道时间缩短成百上千倍。
- **结果**: 成为作者强调"直接学巨人已找到的法则"的核心论据。（第01课）

## A2 — 触发场景 (Future Trigger) ★
### 用户会在什么情境下需要这个 skill?
1. 想从自己或团队的成败经历里沉淀出可复用的方法或认知。
2. 面对反复发生的现象，但说不清它背后的原因或规律。
3. 做复盘/周报/项目总结，需要把"发生了什么"升级成"为什么会这样、以后怎么办"。
4. 想理解某个领域"道"（第一原理），而不满足于记表面规律。
5. 分辨"我找到了规律"和"我找到了本质"之间的差距。

### 语言信号
- "怎么从这次经历里提炼出方法？" / "extract the underlying principle from this experience"
- "这件事反复发生，背后是什么原因？" / "why does this keep happening"
- "复盘一下" / "do a retrospective"
- "底层逻辑/本质是什么" / "what's the root cause / first principle"

### 与相邻 skill 的区分
- 与 `s02-control-variable` 的区别：三归是总框架（归纳→归因→归道），控制变量只是"归因"这一步里提升准确率的子方法。
- 与 `s05-review-model`（复盘）的区别：复盘是三归在"从自己来"场景的具体应用，三归更偏通用思考阶梯。
- 与 `s09-first-principles` 的区别：归道≈找第一原理的近似，但三归覆盖"规律→因果→法则"完整三级，不止终点。

## E — 可执行步骤 (Execution)
1. **归纳（找规律）** — 完成标准：列出至少 2–3 个反复出现的现象，能表述成"每当 X，就 Y"的可观察规律。
2. **归因（找因果）** — 完成标准：对每个规律给出"是什么导致了它"的因果假设；若多个因素纠缠难定，跳到步骤 2a 用控制变量法（s02）逐一固定变量验证；判停：若只找到表象原因（如"玩手机导致熬夜"），则继续追问本质原因（为何克制不住玩手机），不在此停。
3. **归道（找法则）** — 完成标准：把因果继续上溯到可解释多现象的法则/第一原理级陈述，并能举出该法则在其他场景的体现；判停：若证据不足无法归道，先以"规律+因果"的结论落地，标注"待归道"。

## B — 边界 (Boundary) ★
### 不要在以下情况使用
- 只是要记住事实、日期、名词，不必走三归。
- 已有成熟模型可直接套用，且场景适配，无需重新归因。
- 归因要求高精确度时，单靠三归不够，须配合控制变量法（s02）。

### 作者在书中警告的失败模式
- 简单归因：只找表象原因、忽略多因果与系统关系，治标不治本（见 counter-examples ce18 不复盘/简单归因）。
- 经验主义不阅读：只靠自身经验悟道，耗时极长且易错（见 counter-examples ce03）。

### 作者的盲点/时代局限
- 作者承认"因果无法 100% 确定"（休谟问题），三归结论本质是"在一定范围内能解释现象"，非绝对真理；全书把"知识收敛、万物归一"当基石，但作者自承"只是归纳未归道"，未被证实（见 BOOK_OVERVIEW 批判段）。

### 容易混淆的邻近方法论
- 把"归纳出规律"误当"找到本质"：规律可感知，法则需推理，层级不同。
- 与"类比思维"混淆：三归是向上溯源找因果，类比只是横向套用经验（见 counter-examples ce23）。
