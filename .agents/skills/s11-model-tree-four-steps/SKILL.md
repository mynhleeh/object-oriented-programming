# 模型树四步总装（提炼→存入→形成体系→回归本质）

## R — 原文 (Reading)

> "模型树的操作方法特别简单，从大方向来说就是四个步骤：1、提炼模型 2、存入知识 3、形成体系 4、回归本质。"
> "人脑有四大特性：快速遗忘性、高度模糊性、碎片混乱性、难以操作性……必须借助笔记软件来学习，而且必须是能够储存树状知识体系的笔记软件。"

— 兰陵王, 第07课（四步总装 + 外接大脑）

## I — 方法论骨架 (Interpretation)

- 人脑有四大缺陷：忘得快、模糊、碎片、难操作，所以光靠脑子记和理解是不够的，必须把知识外显到一个"外接大脑"（能存树状结构的笔记软件）里。
- 外接大脑的本质是"心理表征显性化"——把脑子里的理解复制成外部可操作的文字，才能随时调取、串联、深想。
- 总装分四步：先用六步阅读法/复盘把知识**提炼**成模型；再把支撑模型的原句**存入**（带序号、关键词、出处、思考）；再按"主题—框架—关系"把模型**形成体系**（树状：以上统下、不重不漏）；最后顺树状结构向上**回归本质**（收敛到更底层的法则）。
- 它不是一套笔记本模板，而是把记忆、理解、思考融为一体的可执行操作流程；前三步是"种树"，最后一步是"向第一原理收敛"。
- 注意：思维导图/笔记本不行——它们承载不了终身知识、也不方便存量，会让知识孤立。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者 2018 年分类归组，演化出"存量思维"/模型树（作者亲历）
- **问题**：作者学了很多知识却记得寥寥、且混乱碎片，难以运用。
- **方法论的使用**：把同一领域知识分类归组、归档在一起，发现重复、看到规律；后来加入"模型"与"外接大脑"，逐步迭代成模型树四步法。
- **结论**：把知识外显并按结构联结，能同时解决记忆、理解、洞察本质；这正是四步总装中"存入知识 + 形成体系"的雏形。
- **结果**：从"学完就忘"转为能不断复习旧知、加深理解，并最终长成模型树学习法。

### 案例 2: 教模型树三年，同学"五马分尸 + 存量"翻车（教学实录）
- **问题**：很多学员反映"感觉不到烧脑"，学习效率低。
- **方法论的使用**：作者定位到翻车点在"抄作业式学习"——原样复制作者观点，且轻视"五马分尸"（以句为单位)与"存量"（摘原句)。
- **结论**：不按句独立提炼、不存量，就只是把书复制一遍，没有真正总装进自己的树。
- **结果**：强调以"一句完整意思的话"为最小学习单位 + 严格存量，学员才进入深度思考。

### 案例 3: 用模型树学 Python（推演示例）
- **问题**：想系统掌握一门新技能/学科，而非零散看教程。
- **方法论的使用**：选能存树状的笔记软件作外接大脑 → 六步提炼模型（拆解/淘金/理解/判断/启发/封装）→ 每个模型下做存量（序号/关键词/出处/思考）→ 按"Python 知识体系"主题形成树状体系 → 回归本质收敛到语言核心机制。
- **结论**：(推演示例，源自 verified.md V2) 四步总装能把一门技能真正内化为可调用、可生长的知识体系。
- **结果**：(推演示例) 学完能体系化调用，而非学过就散。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 读完一本书/上完一门课，想真正"长"成自己的知识，而不是合上书就忘。
2. 知识越学越多却越乱，遇到问题调不出来、串不起来。
3. 想建立某个领域（如销售、投资、编程）的长期知识库。
4. 发现自己一直在"抄作业式学习"，缺乏独立结构与思考。
5. 准备做主题阅读，需要一套可复用的总装流程。
6. 用户想用思维导图/纸质笔记本代替可存树状的笔记软件——激活以拦截（指出承载不了终身存量）。
7. 用户担心坚持不了每天维护笔记软件——激活以说明前提（须承诺长期输入与回顾），而非放弃方法。

- 与 `s08-knowledge-system` 的区别：s08 讲"体系是什么、主题/框架/结构怎么定"；本 skill 把它落到四步操作流程里。

- 与 `s05-review-model` 的区别：复盘的提炼是总装的输入来源之一（从自己来），总装负责把模型种进树。
- 与 `s07-model-definition` 的区别：总装在提炼时调用 s07 的检验标准判断"算不算模型"，s07 是它的一步判据。
- 与 `s10-transfer-create` 的区别：总装把知识种进树，s10 把树里的原理"用出去"（抽象演绎/排列组合）。

## E — 可执行步骤 (Execution)

1. **准备外接大脑** — 完成标准：选定一款能存树状结构的笔记软件，新建一棵以主题为根的树，把心理表征显性化进去。判停：若你只想用思维导图/笔记本（见 ce22），回到本步重选工具，否则知识会被孤立、无法存量。
2. **提炼模型** — 完成标准：以"一句完整意思的话"为单位，经拆解/淘金/理解/判断/启发/封装，产出世界观或方法论模型（从他人来用六步，从自己来用复盘）。
3. **存入知识（存量四要素）** — 完成标准：每个模型下挂原句，且带①序号 ②标关键词 ③出处 ④你的思考；不少于 2–3 条。
4. **形成体系** — 完成标准：确定主题与框架（世界观/方法论），把模型按树状"以上统下、不重不漏"联结，标清关系（因果/层次/中介）。
5. **回归本质（收敛）** — 完成标准：顺树状结构向上追溯，用 MECE 思考，把对立模型统一到更本质的模型/第一原理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 你只想临时应付一次考试或一次性任务——四步总装是终身工程，投入产出不划算。
- 你无法承诺长期维护笔记软件——没有持续输入与回顾，树会枯萎，等于没建。

### 作者在书中警告的失败模式
- **外接大脑误用（ce22）**：用思维导图（只能梳理单篇、不便存量）或笔记本代替可存树状的笔记软件，导致知识孤立、模型树废一半。
- **存量懒惰（ce13）**：提炼后不摘原句或只摘一两条，模型成"无根之水"，无法迭代、易忘初衷。
- **抄作业式 / 我注六经 / 五马分尸被轻视（ce09、ce10、ce11）**：原样复制作者、照搬混乱结构、仍以整本书为学习单位，等于没思考。

### 作者的盲点/时代局限
- 方法高度绑定自研"模型树笔记"软件（BOOK_OVERVIEW 时代局限）：脱离该软件时，树状双链实操成本上升，存在工具依赖与数据迁移风险。
- 认知负荷极高（BOOK_OVERVIEW 立场盲点）："以句子为单位五马分尸 + 终身修剪"对普通人强度要求高，未必比间隔重复+闪卡更高效。

### 容易混淆的邻近方法论
- **思维导图**：只是单篇要点梳理工具，不是可承载终身知识的树状外接大脑。
- **s12 修剪模型树**：本 skill 负责"建"，s12 负责"养"；别把建完不维护当成总装已完成。
