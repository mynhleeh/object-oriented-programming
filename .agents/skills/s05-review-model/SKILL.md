# 从经验提炼模型（复盘）

## R — 原文 (Reading)
> "所谓复盘，就是从分析问题、拿出方案中总结模型。分析问题——提炼模型——世界观；拿出方案——提炼模型——方法论。""达成目的的核心在于四个字『凑齐因果』……避免发生的核心在于四个字『切断因果』。"
> — 兰陵王, 第04课

## I — 方法论骨架 (Interpretation)
- 复盘＝从自己的经验里提炼可复用的"模型"（＝万物法则/意义组块），把一次教训或经验变成以后能直接调用的抓手。
- 复盘产出两类模型：**分析问题→世界观**（事物为何如此运转）；**拿出方案→方法论**（具体怎么做）。
- 方法论的生成靠两条因果操作：要成事就**凑齐因果**（因缘和合，把必要条件集齐）；要避祸就**切断因果**（釜底抽薪，抽掉起因）。
- 原因分表象与本质，必须靠系统思维找齐，必要时回心理学/生物学找本质原因，否则只治表象、反复失败。

## A1 — 书中的应用 (Past Application)
### 案例 1: "从不开始"模型（切断因果）
- **问题**: 一看连续剧第一集就忍不住一口气刷完，熬夜伤身。
- **方法论的使用**: 分析因果（起因＝看了第一集）→ 切断因果（忍住不看第一集）→ 抽象为更普世的"从不开始"。
- **结论**: 上瘾由人性/动力机制驱动，正确做法是切断起因，而非靠脆弱意志。
- **结果**: 有效减少刷剧时间，并泛化到戒烟、戒小说、戒游戏等一切上瘾事物。

### 案例 2: 成交方法论"交换欲/信任感/竞争力"（凑齐因果）
- **问题**: 如何系统提升销售/成交能力？
- **方法论的使用**: 找齐成交的所有原因，凑齐这些因果——交换欲（对方刚好需要）、信任感（对方信你说的是真）、竞争力（对方为何选你而非别人）。
- **结论**: 达成目的＝凑齐因果（因缘和合），把多个因果集齐即得到可操作方法论。
- **结果**: 形成"成交三要素"方法论模型。

### 案例 3: 分析熬夜只治表象（表象 vs 本质原因）
- **问题**: 熬夜总戒不掉。
- **方法论的使用**: 表象原因＝玩手机导致熬夜，于是决定睡前远离手机；本质原因＝为何克制不住睡前玩手机的人性机制。
- **结论**: 只解决表象会失效，必须追溯到本质原因才能根治。
- **结果**: 说明"系统思维找齐因果、追到本质"是复盘分析的必要纪律。

## A2 — 触发场景 (Future Trigger) ★
### 用户会在什么情境下需要这个 skill?
1. 连续在同类事情上踩坑/失败（如连续谈崩客户）。
2. 想把一次成功经验变成可复用的方法。
3. 面对反复出现的问题，想彻底根治而非临时应付。
4. 想从自己的经历中沉淀出"原则/模型"。
5. 发现自己在"晚上千条路，早上走老路"地重复犯错。
6. 用户遇到外部不可控的失败（如客户跑路），想复盘却容易虚假归因——激活以说明只沉淀应对法。

### 语言信号
- "又犯同样的错了"、"这次成功纯靠运气"、"怎么老在这种事上栽跟头"、"老问题又来了"
- "I keep making the same mistake"、"how do I turn this into a method"、"why does this keep happening"
- "这事完全不可控, 我能复盘出什么" / it's totally out of my control, what model can I draw

### 与相邻 skill 的区分
- 与 **s01-san-gui** 的区别: 三归是"归纳/归因/归道"的认知阶梯与向内求路径；本 skill 是复盘产出模型＋因果操作的完整动作。
- 与 **s02-control-variable** 的区别: 控制变量是复盘"归因"时提升准确率的具体工具，本 skill 是其上层流程。
- 与 **s12-prune-model-tree** 的区别: 修剪是在复盘提炼出模型之后，对模型/结构做优化；本 skill 负责"首次从经验产出模型"。
- 与 **s06-six-step-reading** 的区别：复盘从自己经验提炼模型（从自己来），六步阅读从他人书里提炼（从他人来），是获取模型的两种并列路径。
- 与 **s11-model-tree-four-steps** 的区别：复盘产出模型作为总装的输入来源，总装负责把模型种进树（提炼→存入→体系→回归）。

## E — 可执行步骤 (Execution)
1. **分析问题 → 提炼世界观** — 完成标准: 列出导致该结果的全部因果（表象+本质），至少追溯到一个本质原因。; 判停: 若只找到表象原因（如"玩手机导致熬夜"），继续追问"为什么克制不住"，直到触及本质（人性/机制），否则方案会失效。判停: 若原因完全外部不可控（如客户跑路），停止强行因果，只沉淀"应对法"（识别/规避/止损），不做因果归因。
2. **拿出方案 → 提炼方法论** — 完成标准: 按目的二选一——要成事则"凑齐因果"（列出所有必要原因并补齐，如成交三要素）；要避祸则"切断因果"（抽掉起因，如"从不开始"）；写成一句话模型。; 判停: 若方案依赖"靠意志力硬扛"，回到切断因果（意志脆弱，不可靠）。
3. **抽象归并 → 收敛** — 完成标准: 把具体模型向上抽象一层（如"不看第一集"→"从不开始"→人性层面），并标注适用边界、挂入已有模型树（树状收敛）。

## B — 边界 (Boundary) ★
### 不要在以下情况使用
- 单次偶然事件，无需复盘沉淀。
- 问题纯属外部不可控（只能沉淀"应对法"而非因果）。
- 只想宣泄情绪、不打算改进时。

### 作者在书中警告的失败模式
- 不复盘/经验随风飘散（ce18）: 经验不经过大脑、不沉淀，一年的经验等于一天；且习惯简单归因只找表象。
- 盲目相信意志力（ce19）: 对抗上瘾靠意志硬扛，应改用"切断因果"，否则反复失败。

### 作者的盲点/时代局限
- 复盘得到的"模型/法则"只是当前最可靠假设，非绝对真理（波普尔可证伪性反驳朴素基础主义，见 BOOK_OVERVIEW 批判段）。
- "每年大修剪"隐含高时间投入假设；把问题归因于"不肯深度思考/不肯复盘"，低估执行门槛。
- 因果无法 100% 确定（休谟问题），现实只能靠大数据近似找齐因果。

### 容易混淆的邻近方法论
- 与 s01-san-gui 混淆: 三归偏认知阶梯，本 skill 偏"产出模型+因果操作"。
- 与 s07-model-definition 混淆: s07 是"模型＝意义组块"的定义与检验，本 skill 是提炼操作本身。
- 与"写复盘日记"混淆: 本 skill 不止记录，必须析出可复用的世界观/方法论模型。
