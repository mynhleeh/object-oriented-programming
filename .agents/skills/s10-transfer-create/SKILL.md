# 超级迁移与创造（先抽象后演绎 + 第一原理排列组合）

## R — 原文 (Reading)

> "真正的迁移能力绝对不是简单的类比，而是一种先抽象后演绎的能力……迁移能力的本质……就是知识的重叠。"
> "所谓创造能力，其实就是第一原理的排列组合。"
> "第一原理 + 演绎思维……只有在第一原理之上进行演绎推理，才能保证结论的正确性。"

— 兰陵王, 第06课（迁移 / 创造 / 决策三段）

## I — 方法论骨架 (Interpretation)

- 大多数人以为"迁移"就是把 A 领域的经验照搬到 B 领域，这其实是低级的类比，换层皮而已。
- 真正的迁移分两步：先把具体问题**抽象**到支配它的底层法则，再把这个法则**演绎**回另一个具体场景——两件事之所以能互通，是因为被同一条第一原理所支配。
- "创造"也不是凭空冒出新点子，而是把多个已掌握的底层原理拿来做**排列组合**：像主厨懂食材与火候的原理后能不断出新菜，而非厨师照食谱微调。
- 决策层面，只要起点是可靠的第一原理、推理链严谨，结论就"从真到真"地可靠，不依赖经验类比或主观感受。
- 这套能力的天花板，取决于你脑中底层原理的数量与深度——原理越多越底层，迁移越广、创造越强、决策越稳。
- 因此它和"第一原理思维"是配套使用的：s09 负责"找到"原理，本 skill 负责"用"原理去迁移、创造、决策。

## A1 — 书中的应用 (Past Application)

### 案例 1: "从不开始"的逐级抽象（超级迁移，作者亲历）
- **问题**：作者刷连续剧上瘾，且推而广之，生活中存在各种上瘾物（小说、游戏、烟、毒）。
- **方法论的使用**：先抽象出"不看第一集"，再抽象为"从不开始"，最后抽象到人性/上瘾本质层面。
- **结论**：迁移的本质是先抽象后演绎——每抽象一次，就能举一反三解决一大片问题；抽象到第一原理，就能覆盖所有相关问题。
- **结果**：一个"从不开始"模型，泛化解决了全部上瘾类问题，而非每次重新想办法。

### 案例 2: 主厨 vs 厨师（创造本质，书中作者阐释）
- **问题**：为什么有的人能不断推陈出新，有的人只能对现有方案稍作改良？
- **方法论的使用**：作者借马斯克的比喻区分——主厨掌握味觉原理与食材反应，能排列组合出无数新菜；厨师只拿食谱做菜。第一原理思维者即"主厨"。
- **结论**：创造 = 第一原理的排列组合；创造力的强弱 = 掌握底层原理的数量 × 深度 × 组合能力。
- **结果**：回到第一原理思考（如把"马"拆成动力系统+运动系统），才能跳出"更快的马"、创造汽车/火车/飞机。

### 案例 3: 用第一原理做正确决策（推演示例）
- **问题**：面对"某件事做不了""要不要赌一把"之类决策，凭经验或感觉容易错。
- **方法论的使用**：把决策建立在可演绎验证的第一原理上（如芒格"概率不站我这边就不赌"、贝索斯把战略建立在"更低价格/更快配送/更多选择"三条不变人性上）。
- **结论**：从真到真的演绎能保证结论正确；凡决策须有第一原理支撑，拒绝经验层/主观层的理由。
- **结果**：(推演示例) 高确定性决策，避免被表象与类比带偏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想把一篇文章的洞察、一个行业的打法，套用到自己的新领域/新项目。
2. 想做出真正新颖的方案、产品、文章，而非在旧框架上微调。
3. 面临人生或业务的关键决策，希望不是拍脑袋、不是抄同行。
4. 学了很多模型却"用不上""想不到怎么连起来"。
5. 被要求"举一反三""跨界借鉴"但不知从何入手。
6. 用户想类比/照搬竞品或他人做法（"照着做就行了吧"）——激活以重定向到第一原理层迁移。
7. 用户想做颠覆式创新但自认原理储备不足——激活以判停并引导先去 s09-first-principles 积累底层原理。

### 语言信号
- "这个方法能不能用到别的地方？" / Can this be applied elsewhere?
- "怎么才能创新/搞点不一样的？" / How do I actually create something new?
- "到底该不该做这件事？" / Should I even do this?
- "这两个事好像是一回事？" / These two things feel like the same principle?
- "照着同行做就行了吧" / just copy what competitors do
- "我想创新但原理不够" / I want to innovate but lack first principles

### 与相邻 skill 的区分
- 与 `s09-first-principles` 的区别：s09 解决"怎么找到第一原理"，本 skill 解决"找到之后怎么用它去迁移/创造/决策"。
- 与 `s11-model-tree-four-steps` 的区别：总装是把知识种进树里；本 skill 是把树里的原理"用出去"。
- 与 `s08-knowledge-system` 的区别：s08 关注知识之间的关系结构；本 skill 关注跨场景的打通与生成。

## E — 可执行步骤 (Execution)

1. **抽象到第一原理** — 完成标准：能从眼前具体问题里说出支配它的底层法则（"这件事的本质是……"）。判停：若你尚未掌握足够底层原理，跳到 s09 先积累原理，再回来迁移创造，避免退化成类比。
2. **演绎回具体场景** — 完成标准：能从该第一原理推演出解决新场景的可操作做法，而非只说"原理相通"。
3. **排列组合创造** — 完成标准：列出已掌握的多个第一原理，尝试两两/多组合，产出至少一个新的方案或视角。
4. **从真到真决策** — 完成标准：关键决策能写成"因为第一原理 X 成立，且推理链严谨，所以选 Y"的形式，经得起演绎检验。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 你尚未掌握足够底层原理，却硬要"创造/迁移"——此时只会是表面类比，不是真迁移。
- 领域尚新、第一原理模糊时，强行"从真到真"反而比借鉴经验更冒险。

### 作者在书中警告的失败模式
- **类比思维主导（ce23）**：把"别人都这么做/我做过类似的"当迁移，只能渐进改良，看不透本质、创不出新东西。
- **知识不收敛（ce25）**：把知识当孤立发散的，不去抽象到共同第一原理，永远"学不完、用不连"。
- **只抽象不还原 / 只还原不抽象（ce17）**：满嘴第一原理却解决不了眼前问题，或只会套具体操作不懂原理。

### 作者的盲点/时代局限
- 作者把"绝对为真的起点知识"作为迁移创造的底座，带有朴素基础主义色彩（见 BOOK_OVERVIEW 批判段：波普尔"可证伪性"指出多数领域只有"当前最可靠假设"，极少有绝对为真的起点）。实操中应以"当前最可靠假设"替代"绝对为真"，并保持可修正。
- 创造力的"排列组合"说偏向哲科思维，对高度依赖审美、情境、协作的领域解释力有限。

### 容易混淆的邻近方法论
- **类比思维**：本 skill 明确反对把简单类比当迁移；真迁移必须走到"共同第一原理"这一层。
- **s09 第一原理思维**：本 skill 是"用"原理，s09 是"找"原理，二者不要混为一谈。
