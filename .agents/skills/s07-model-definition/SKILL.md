# 模型的定义、检验与正确使用

## R — 原文 (Reading)
> 模型就是具体的抽象。模型就是万物法则。模型跟字数无关！模型就是函数法则——定义域是因果中的因，对应法则是因果本身，值域是果，所以模型能解释过去、预测未来。
> — 兰陵王, 第04课《模型思维》

## I — 方法论骨架 (Interpretation)
- 模型不是"套路""模板"或"四字成语"，而是从具体事件里抽象出的**规律、因果、法则**，是学习的基本单位。
- 真正的模型必须能**解释过去、预测未来**（即"意义组块"）：给一个输入，经模型能推出结果；给结果能反推起因。揭示不了因果、给不了启迪的，只是普通组块，不是模型。
- 模型**跟字数无关**。四字只是人脑记忆组块（工作记忆约4块）的压缩便利，字数≠本质。
- 模型有两大使用铁律：**①每个模型都有适用边界**（无绝对真理，只有相对真理）；**②抽象与还原同样重要**（既要底层原理，也要可落地方法论）。
- 检验模型的"试金石"是函数法则图：把候选内容套进 x→f(x)→y，看它能否揭示因果、能否预测。

## A1 — 书中的应用 (Past Application)
### 案例 1: 训练营同学把"巨人刘秀祥"当模型
- **问题**: 有同学读刘秀祥故事，提炼出"模型"叫「巨人刘秀祥」，自认掌握了规律。
- **方法论的使用**: 用函数法则检验——拿它去套，能揭示什么因果？什么也没有，给不了任何运转规律的启迪。
- **结论**: 这只是一个记忆组块，不是模型；真模型=意义组块（如「唇亡齿寒」能告诉你邻国被灭你也危险）。
- **结果**: 确立"模型=意义组块"的判别标准，澄清组块≠模型。

### 案例 2: 作者花几年统一模型本质为"具体的抽象/万物法则"
- **问题**: 各大家对模型定义混乱——套路、临界知识、有效策略、世界简化，莫衷一是。
- **方法论的使用**: 作者从"意义组块"→"函数法则"→"具体的抽象"→"万物法则"逐级收敛，借数学函数与老子"道"统一各说。
- **结论**: "模型就是具体的抽象、模型就是万物法则"是模型本质的终极定义。
- **结果**: 终结模型定义的争论，指出模型可是一句话、一段话、一个故事，唯一标准是揭示规律/因果/法则。

### 案例 3: 作者写《适用边界》强调模型边界+多元
- **问题**: 人们误用格言，比如对几乎不读书的人讲"尽信书不如无书"，或对冲突谚语（英雄出少年 vs 大器晚成）无所适从。
- **方法论的使用**: 用"适用边界+多元模型"双原则检验：模型只在特定条件下成立。
- **结论**: 没有绝对真理，只有相对真理（在边界内为真）；用多个模型看一件事避免"看什么都是钉子"。
- **结果**: 提醒读者须知模型失效条件，才配拥有该知识（芒格）。

## A2 — 触发场景 (Future Trigger) ★
### 用户会在什么情境下需要这个 skill?
1. 用户质疑"我总结的X到底算不算模型？"
2. 用户把知识点强行压成四字就以为得到了模型。
3. 用户用单一格言/模型硬套所有情境，遇到冲突说法无法取舍。
4. 用户想判断某条经验、某篇爆款标题能否提炼成可复用的模型。
5. 用户分不清"组块"与"模型"，存了一堆标签却用不出。

### 与相邻 skill 的区分
- 与 `s09-first-principles` 的区别：模型是"法则级"成果、不要求绝对为真；第一原理要求"绝对为真的起点知识"，更严格。模型逼近第一原理，但不必到第一原理。
- 与 `s08-knowledge-system` 的区别：本 skill 审视**单个模型**的定义与检验；知识体系审视模型之间的**关系与结构**。
- 与 `s11-model-tree-four-steps` 的区别：总装在流程中调用本 skill 的检验标准来判断"提炼出的算不算模型"，本 skill 是它的一步判据。

## E — 可执行步骤 (Execution)
1. **识别候选模型的类型** — 完成标准：明确它是世界观（解释因果/规律）还是方法论（解决某类问题的做法）；若两者都不是（只是专有名词/事件名），跳到步骤2判为组块。
2. **函数法则检验** — 完成标准：套入 x（输入/因）→f(x)（模型）→y（输出/果），能解释过去或预测未来即通过；判停：若揭示不了任何因果、给不了启迪，则它**只是组块不是模型**，不进入模型树，仅作记忆打包。
3. **适用边界与多元校验** — 完成标准：为通过检验的模型标注其成立条件（何时失效），并准备至少1个互补模型，避免用单一模型解释一切。

## B — 边界 (Boundary) ★
### 不要在以下情况使用
- 把"四字压缩"本身当成模型本质（形式≠内容）。
- 用单一模型解释所有事，忽略其适用边界。
- 只学抽象原理或只学具体方法论，忽视"既要抽象也要还原"。

### 作者在书中警告的失败模式
- 把组块当模型（如"巨人刘秀祥"）：无启迪，不是真模型（ce14）。
- 误以为模型=四字压缩：强行压字数是大错（ce15）。
- 忽视适用边界、用单一模型解释一切：冲突模型面前不知取舍（ce16）。
- 只抽象不还原或只还原不抽象：学用脱节（ce17）。

### 作者的盲点/时代局限
- "无绝对真理只有相对真理"——作者带朴素基础主义色彩：追求"绝对为真的第一原理"被波普尔可证伪性反驳，多数领域只有"当前最可靠假设"。
- "模型跟字数无关、四字只是组块压缩"成立，但四字成语式表达在跨语言/跨领域迁移时可能损失精确性。

### 容易混淆的邻近方法论
- **组块**（纯记忆压缩单元，可无意义）vs **模型**（有意义组块，须揭示因果）。
- **类比思维**（照搬相似经验）vs **模型思维**（抽象出支配法则）。
